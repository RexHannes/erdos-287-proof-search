# GRAVEYARD / retired

These routes are not necessarily false. They are no longer appropriate controlling targets because they are overstrong, source-mismatched, quantitatively nonclosing, or make an invalid inference.

Current examples:

- independent unweighted covariance norms that discard the physical `lambda(b)` weight;
- per-prime insertion of the single global singular-series normalization;
- treating `Z(s,s)=0` alone as a bound for the directed Perron anti-diagonal;
- identifying the complete-period endpoint main with the complete joined covariance;
- demanding an independent medium-`k` closure before the two-high sector. The current source recompiles those sibling pieces into one signed selector parent; medium-`k` is therefore retired **as an independent sequential node**, not declared globally proved.
