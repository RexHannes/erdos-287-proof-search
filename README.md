# Erdős Problem #287 - Public Draft

This repository contains a public review draft concerning Erdős Problem #287.

The paper develops a conditional Sophie-prime reduction together with a Lean-verified finite obstruction. It is a research draft and does **not** claim a complete solution of Erdős Problem #287, the Twin Prime Conjecture, or the Sophie Germain prime conjecture.
