# GRAVEYARD — routes that should not control new proof search

This directory is a **semantic no-reopen index**. It does not mean every item here is mathematically false.

- [`false/`](false/) — actual counterexamples, false universal statements, or explicitly retracted factual claims;
- [`retired/`](retired/) — may be meaningful mathematics, but the requested theorem is overstrong, quantitatively nonclosing, source-mismatched, or no longer a useful consumer;
- [`superseded/`](superseded/) — legitimate older coordinate systems replaced by a more source-minimal parent formulation.

Historical source files are preserved in [`../archive/`](../archive/) and Git history. The purpose of this folder is to stop later proof-search runs from repeatedly rediscovering a dead route under a new name.

**Rule:** `not currently controlling` does not imply `proved`; `retired` does not imply `false`.
